# Security Policy

## Supported Versions

Security updates are provided for the latest stable release.

## Reporting a Vulnerability

Please do not disclose security vulnerabilities publicly.

Instead:

- Open a private vulnerability report through GitHub (if enabled), or
- Contact the maintainers directly.

Include:

- Description of the issue
- Steps to reproduce
- Potential impact
- Suggested mitigation (if known)

We aim to:

- acknowledge reports promptly
- investigate responsibly
- provide updates throughout the process
- release fixes as quickly as practical

Thank you for helping keep BEACN secure.
