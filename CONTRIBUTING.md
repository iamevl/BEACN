# Contributing to BEACN

Thank you for your interest in contributing.

BEACN welcomes bug reports, feature requests, documentation improvements and code contributions.

## Before You Begin

Please:

- Read the Vision document.
- Read the Engineering Principles.
- Search existing issues before creating a new one.

## Development Philosophy

BEACN values:

- readable code
- maintainability
- simplicity
- documentation
- thoughtful design

Features should solve real problems without introducing unnecessary complexity.

## Pull Requests

Please:

- Keep pull requests focused.
- Update documentation where appropriate.
- Add or update tests where practical.
- Explain the reasoning behind significant architectural changes.

## Reporting Bugs

Include:

- BEACN version
- Operating system
- Steps to reproduce
- Expected behaviour
- Actual behaviour

## Feature Requests

Explain:

- the problem you're solving
- why existing functionality is insufficient
- any proposed solution

## Questions

If you're unsure, open a discussion before implementing a major feature.

We appreciate every contribution, no matter how small.
