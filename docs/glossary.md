# Glossary

## Device
A physical or virtual endpoint known to BEACN.

## Discovery
The process of identifying devices on infrastructure.

## Observation
A point-in-time fact collected about a device.

## Inventory
The canonical record of known devices.

## BEACN Agent
An optional service providing enhanced telemetry.

## BEACN Core
The backend service responsible for discovery, inventory and APIs.

## BEACN Console
The web interface used to interact with BEACN.
