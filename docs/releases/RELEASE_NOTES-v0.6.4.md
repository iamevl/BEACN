# BEACN v0.6.4

## Chart & Health Polish

### Added
- Hover over a hardware history chart to see the exact reading and timestamp.
- Current-value chips on CPU temperature, CPU power, GPU load and memory history.
- Green, amber and red health states for CPU temperature, CPU load and memory load.
- Clear idle state for low GPU activity.

### Preserved
- SQLite WAL mode and serialised write protection from v0.6.3.
- Existing history database and collected metrics.
